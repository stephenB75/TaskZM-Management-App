# App Store screenshots (v2.0.0)

Upload the files in `iphone-6.9/` and `ipad-13/` to App Store Connect in filename order. `raw/` holds the uncaptioned captures at the same resolution, for other uses or for redoing captions.

| Folder | App Store Connect slot | Size |
|---|---|---|
| `iphone-6.9/` | iPhone 6.9" Display | 1320 × 2868 (portrait) |
| `iphone-6.5/` | iPhone 6.5" Display | 1284 × 2778 (portrait) |
| `ipad-13/` | iPad 13" Display | 2752 × 2064 (landscape) |
| `ipad-12.9/` | iPad 12.9" Display | 2732 × 2048 (landscape) |

Each folder only fits its own device tab in App Store Connect; dropping a set into a different tab gives a "dimensions are wrong" error. Uploading the 6.9" and 13" sets is enough, since App Store Connect scales them down for smaller devices. Use the 6.5" and 12.9" sets only if App Store Connect asks for those tabs.

## Upload-ready JPEGs (`upload/`)

Use these if App Store Connect rejects the PNGs. They are flattened JPEGs (no alpha) with an embedded sRGB profile, one folder per accepted size. Each slot accepts either size listed for it, so if one is refused, try the other.

| Folder | App Store Connect tab |
|---|---|
| `upload/iphone-6.9_1320x2868/` or `upload/iphone-6.9_1290x2796/` | iPhone 6.9" Display |
| `upload/iphone-6.5_1284x2778/` or `upload/iphone-6.5_1242x2688/` | iPhone 6.5" Display |
| `upload/ipad-13_2752x2064/` | iPad 13" Display |
| `upload/ipad-12.9_2732x2048/` | iPad 12.9" Display |

Check the tab name above the drop zone before dragging files in: the iPhone sets only fit iPhone tabs, and the landscape iPad sets only fit iPad tabs.
